After Start, Koia lists your scenes or, if there are none yet, opens New Scene where you load a file. Activate a scene with play_circle_outline; Koia opens its raw data.

  • Explore raw data

    Sort columns and narrow the data with add_circle_outline Add Filter (value or value range filters). Click any chart element or summary value to see the rows behind it.

  • Pivot table

    Press add next to the view tabs and choose New Pivot Table. Drag column names into the row and column areas.

  • Dashboard

    Press add and choose New Dashboard. A dialog asks for the first element: chart, relationship graph or summary table. Add more from the dashboard toolbar with .

  • settings

    Configure elements

    Press settings on any dashboard element to open its side bar and pick columns, chart type, grouping and colors. Save the view with save_alt and restore it later with open_in_browser.
