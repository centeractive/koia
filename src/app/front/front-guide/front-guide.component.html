Once your data is loaded, Koia opens its raw data. Add views as tabs next to it.

  • Explore raw data

    Sort columns, narrow rows with Add Filter and click any chart element or value to see the rows behind it.

  • Pivot table

    Press add next to the tabs, choose New Pivot Table and drag columns into place.

  • Dashboard

    Press add, choose New Dashboard and combine charts, graphs and summary tables.

  • settings

    Configure elements

    Press settings on an element to pick columns, chart type and colors.
