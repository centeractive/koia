Why Koia?

  • Open-source

    Free and publicly available. Use it online or install it in your own trusted environment.

  • Your data stays private

    Data only travels between your browser and the storage you choose: the browser itself or your own CouchDB.

  • CSV, Excel, JSON

    Import files and decide which columns are loaded and how values are typed and formatted.

  • Raw data one click away

    Click any chart element or summary value to see the rows behind it. The context is never lost.

Features

Load your data

Import a CSV, Excel or JSON file and decide which columns are loaded and how values are typed.

Each data set becomes a scene. Switch between scenes in a single browser tab.

  • CSV
  • Excel
  • JSON
  • Retrospective Log Analyzer

Pivot tables and charts

Drag columns into a pivot table and switch between heatmaps, bar charts and more.

Pick from pie, doughnut, bar, line, area, radar, polar area and scatter charts.

  • Heatmaps
  • Relationship graphs
  • Time series

Dashboards

Combine charts, relationship graphs and summary tables on dashboards, in a grid or flex layout.

Each element has a side bar to pick columns, chart type, grouping and colors.

  • Grid layout
  • Flex layout
  • Saved views

Drill into raw data

Click any chart element or summary value to see the rows behind it.

Narrow every view with time and value filters and export results.

  • Time filters
  • Value filters
  • Excel export
  • PNG export

How it works

  1. Open KoiaNo sign-up. Data stays in your browser unless you choose CouchDB.
  2. Load a file or try sample dataImport CSV, Excel or JSON, or explore ready-made fruit sales views.
  3. Create viewsAdd pivot tables and dashboards with charts, graphs and summaries.
