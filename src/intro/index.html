What is Koia?

Koia is an open-source web application for visualizing and analyzing table-like data structures. It is a simple and privacy-focused tool for everyone who just wants to create graphs without having to be worried about registration or subscription fees.

  • Open-source

    The source code is and will always be publicly available and can be inspected, modified and enhanced by anyone. Koia can also be installed in your trusted environment.

  • Your data stays private

    Your data never flows back to the website. It only travels between your browser and the data storage you choose, locally or in a private external database.

  • CSV, Excel, JSON

    Load your structured data from files and keep full control over which portions are imported and how values are typed and formatted.

  • Switch between scenes

    Each loaded data set is a scene. Switch between scenes in one browser tab to create graphs based on different data.

Why Koia?

With Koia, you can effortlessly create meaningful graphs while having total control over your data. The context to the original data is never lost. You are always only a mouse click away from seeing the raw data on which the displayed element or value is based.

Koia features time and value filters to present a closer look at diagrams and the numbers behind them. When satisfied with the outcome, you can save the current view or export data to use it elsewhere.

Loading data

Data loaded from an individual file are represented by a scene. You can switch between different scenes as you please to create diagrams based on different data.

It is also possible to load data through a third party program like Retrospective Log Analyzer.

Visualize data

The data can be viewed and sorted in a raw data table or it may be refined and displayed as charts, relationship graphs, summary or pivot tables with a few mouse clicks.

Koia offers a variety of chart types such as pie charts, doughnut charts, bar charts, radar charts, polar area charts, line charts, area charts and scatter charts.

Dashboards

Combine charts, relationship graphs and summary tables on dashboards. Arrange the elements in a grid of customizable dimension or let them flow in a flex layout.

Any number of pivot tables and dashboards may be opened as tabs next to the raw data table and are kept with the scene.

Time series

Follow values over time in line and area charts and summarize them per day, month or year.

Drag the time range slider to narrow every chart and summary of the view at once.

Configure with a few clicks

Every chart, relationship graph and summary table has its own side bar. Pick value columns, chart type, grouping, aggregation, colors and scales and see the element adapt instantly — no formulas, no wizards.

Relationship graphs

Explore how values relate across columns in interactive force-directed graphs; bubble size reflects the number of related rows.
