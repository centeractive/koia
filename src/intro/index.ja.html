Koia を選ぶ理由 機能 使い方 GitHub EN DE JA Koia を開く

あなたのデータからグラフ、ピボットテーブル、ダッシュボードを

ブラウザーだけで。オープンソースで登録不要、データは常にあなたの管理下にあります。

はじめる

Koia を選ぶ理由

  • オープンソース

    無料で公開されています。オンラインで使うことも、信頼できる自社環境にインストールすることもできます。

  • データは非公開のまま

    データがやり取りされるのは、ブラウザーと選択したストレージ（ブラウザー自体または独自の CouchDB）の間だけです。

  • CSV, Excel, JSON

    ファイルをインポートし、読み込む列と値のデータ型・書式を指定できます。

  • ワンクリックで元データへ

    グラフの要素や集計値をクリックすると、その元になった行を表示できます。コンテキストが失われることはありません。

機能

データを読み込む

CSV、Excel、JSON ファイルをインポートし、読み込む列と値のデータ型を指定します。

各データセットはシーンになります。1 つのブラウザータブでシーンを切り替えられます。

  • CSV
  • Excel
  • JSON
  • Retrospective Log Analyzer

ピボットテーブルとグラフ

列をピボットテーブルにドラッグし、ヒートマップや棒グラフなどを切り替えられます。

円グラフ、ドーナツグラフ、棒グラフ、折れ線グラフ、面グラフ、レーダーチャート、鶏頭図、散布図から選べます。

  • ヒートマップ
  • 関係グラフ
  • 時系列

ダッシュボード

グラフ、関係グラフ、サマリーテーブルをダッシュボード上にグリッドまたはフレックスレイアウトで組み合わせられます。

各要素のサイドバーで列、グラフの種類、グループ化、色を選択できます。

  • グリッドレイアウト
  • フレックスレイアウト
  • 保存済みビュー

元データを掘り下げる

グラフの要素や集計値をクリックすると、その元になった行を表示できます。

時間フィルターと値フィルターでビューを絞り込み、結果をエクスポートできます。

  • 時間フィルター
  • 値フィルター
  • Excel エクスポート
  • PNG エクスポート

使い方

  1. Koia を開く登録不要。CouchDB を選ばない限り、データはブラウザー内に保存されます。
  2. ファイルを読み込むかサンプルデータを試すCSV、Excel、JSON をインポートするか、用意された果物の売上ビューを試せます。
  3. ビューを作成グラフ、関係グラフ、サマリーを含むピボットテーブルとダッシュボードを追加できます。
